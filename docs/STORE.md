# 应用商店文案

> 用于提交应用商店时填写，文案不包含具体第三方产品名。

## 应用名称

```text
FnRelay 反代
```

## 一句话简介

```text
飞牛 OS 原生反向代理：单端口 HTTP/HTTPS、自动加载证书，从桌面统一管理内网 Web 服务。
```

## 短描述

```text
FnRelay 用同一个端口同时处理 HTTP 和 HTTPS，自动加载飞牛证书，按域名转发到 NAS 上的 Web 服务，管理界面只从飞牛桌面打开。
```

## 长描述

```text
FnRelay 是运行在飞牛 OS 上的原生反向代理应用。

它用同一个代理端口同时处理 HTTP 和 HTTPS，自动加载飞牛证书，按精确域名或泛域名把请求转发到 NAS 上的 Web 服务。

管理界面直接内嵌在飞牛桌面，不开放独立管理网页端口，也不需要 FnRelay 密码；权限跟随飞牛管理员登录态。

支持 HTTP → HTTPS 跳转、WebSocket / SSE、实时访问、访问与审核日志、域名批量替换、配置备份与恢复，以及亮色 / 暗色主题。
```

## 功能亮点

```text
· 单端口同时处理 HTTP 和 HTTPS
· 自动加载飞牛证书，按 SNI 选择证书
· 精确域名 + 泛域名匹配
· HTTP → HTTPS 自动跳转
· WebSocket / SSE / 流式响应
· 实时访问与上下行速度
· 访问 / 审核日志，可选本地保存
· 域名后缀批量替换
· 配置备份与版本校验恢复
· 飞牛桌面内嵌管理，无独立管理端口
```

## 适用场景

```text
· 给家庭媒体、下载、自动化等 Web 服务配自己的域名和 HTTPS
· 把局域网 IP:端口 服务统一成域名访问
· 需要泛域名、多个子域共用一个入口
· 不想再维护独立的反向代理面板
```

## 上架前检查

当前 FnRelay 需要以 root 运行，并监听 80/443、读取证书私钥。提交前先确认飞牛对第三方 root 应用和特权端口的审核要求；如果商店不允许，需要改特权 helper 或端口转发方案。
